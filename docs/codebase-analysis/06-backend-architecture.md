### Layer separation assessment

Most controllers translate HTTP; most use cases enforce lifecycle rules and DTO mapping. Exceptions: communications/notifications handlers use Prisma directly; scorecard/form use cases contain Prisma operations in transaction callbacks; repositories also own rules. Factory composition is repeated and organization-module.js is broad. Phase 3C repaired E06. Email provider dispatch remains outside DB transactions; Phase 3D separates provider failures from post-acceptance persistence failures, while exactly-once delivery and durable reconciliation remain unsolved.
