### Reporting semantics and consistency

Analytics mixes event-window metrics (received applications, sent/accepted timestamps, outcome events) with current snapshots (active/open jobs, current stages, current offer states, pool totals). Funnel is not a cohort conversion funnel: independently counted events can produce non-monotonic values. Time-to-hire uses the most recent HIRED event per application in the requested window. Communication success rate is sent/(sent+failed), excluding pending, not proof of delivery to inbox. No cross-query snapshot transaction is used for overview Promise.all, so concurrent changes can yield slightly different observation times.
