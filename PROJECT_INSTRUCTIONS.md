# HiringLoop Project Instructions

## Repository Rules

- Keep the frontend and backend as separate Node.js applications inside this single Git repository.
- Maintain separate dependencies, configuration, build, and test setup for each application.
- Do not initialize nested Git repositories.
- Do not use Nx, Turborepo, npm workspaces, pnpm workspaces, or microservices at this stage.

## Current Scope

- SETUP-00 is repository organization only.
- Do not implement product features or initialize application frameworks until explicitly requested.
- Do not introduce React, Express, Prisma, PostgreSQL, Redis, BullMQ, S3, authentication, or database schemas during setup.

## AI Engineering

AI engineering is explicitly deferred until the software engineering milestone is complete. Do not implement AI functionality during the current software engineering phases.
